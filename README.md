# ME Beam Formers

Beams that carry an ME network across open space, for
[AE2 Unofficial Deconstructed](https://github.com/romanfedyniak/AE2UD), for Minecraft 1.12.2.

Two beam formers facing each other along a line join their networks with a visible beam, as long as nothing
solid stands between them. Beam towers link to each other at any angle, several links to a tower, paired with
a memory card. The mod adds three things:

- **Small Beam Former**, a part on a cable bus, carrying 8 channels.
- **Dense Beam Former**, a block mounted on a surface, carrying 32 channels.
- **Beam Tower**, a block linked to other towers, carrying 32 channels on each link.

It is written from scratch. Its ideas come from [ME Beam Former](https://modrinth.com/mod/me-beam-former) by
GaLicn, for modern Minecraft, and from the beam formers of [NAE2](https://github.com/AE2-UEL/NAE2), for 1.12.2
on AE2 UEL.

## Compatibility

- This mod runs only with AE2 Unofficial Deconstructed, not with standard AE2 or AE2 Unofficial Extended Life.
- Back up the world before installing or updating.
